# DuoPlus-Cloud-Phone
海外云手机。支持云游戏项目、海外社媒营销、广告联盟、web3项目，一站式管理多账号工具。

---

## 🚀什么是 DuoPlus 云手机？

DuoPlus云手机是基于云端的 **Android 手机服务（Cloud Phone）**，无需实体手机，用户可以在云端创建、管理和控制多台虚拟 Android 设备，正常运行移动应用程序。

每一台云手机都运行在**相互隔离的系统环境**中，拥有独立的系统数据、存储空间和设备环境指纹，适合需要**长期稳定运行、账号隔离和自动化操作**的业务场景，安全防关联。

DuoPlus云手机常见应用于：
- 海外社交媒体多账号运营  
- 跨境电商多店铺管理  
- 广告投放与联盟账号管理  
- 游戏养号

---

## 🌐架构概览

DuoPlus云手机采用与真机一样的ARM芯片，生成独立干净的 Android 设备环境，兼顾稳定性、可扩展性与自动化能力。

- **真实 ARM 架构环境**  
  云手机运行在海外部署的 ARM 架构服务器上，系统环境与实体 Android 手机高度一致，相比传统 x86 模拟器，更不易被识别为虚拟设备。

- **独立隔离的 Android 系统**  
  每一台云手机都拥有独立的系统实例、存储空间和运行进程，确保账号与设备环境之间互不干扰。

- **多 Android 版本支持**  
  支持多种 Android 系统版本，包括Android 10/11/12/15，提升应用兼容性，满足主流及新兴海外应用的运行需求。

- **集中式管理控制层**  
  所有云手机、账号和自动化任务均可在统一平台中集中管理，适合规模化运营。

## 💥功能特性（Features）

- **操作同步功能**
  实时同步主机的操作，便于批量操作多台云手机。

- **RPA 自动化支持**  
  支持自定义创建流程，适用于批量注册登录等需要重复操作的任务。

- **云号码功能（Cloud Number）**  
  支持在线接收短信验证码，无需插卡，集中管理多个号码。

- **API 接口支持**  
  提供功能控制接口，便于系统集成与快速操作云手机。

- **云端数据存储**  
  云手机数据长期保存在云端，便于持续使用和管理。

- **高可扩展性**  
  支持批量创建和管理云手机实例，满足大规模业务需求。

## 🧩使用场景（Use Cases）

通过多台云手机实现账号隔离的效果，适用于社交媒体、电商、广告等多账号运营场景。

### 海外社交媒体运营
在原生海外环境中运行 TikTok、Instagram、X、Telegram等应用，支持注册、养号和日常操作。

### 云手机集群 / Phone Farm
在云端构建大规模手机集群，用于游戏挂机、应用测试或批量操作。

### 短信验证码与云号码
在云手机中直接接收短信验证码，适合长期业务账号绑定。

### 长时间运行任务
支持 24/7 持续运行的任务场景，如挂机、后台操作等。

## 👋快速开始（Getting Started）

1. **注册 DuoPlus 账号**  
   在 DuoPlus 官方平台注册并创建账号（https://www.duoplus.cn/share/github）

2. **创建云手机实例**  
   创建新的云端 Android 手机，包括设置云手机仿真参数和配置全球国家代理IP。

4. **安装并运行应用**  
   在云手机中下载并安装所需的海外应用，例如TikTok、Facebook、Telegram、Instagram、Pinterest、Reddit。

5. **配置自动化（可选）**  
   使用 RPA 脚本或 API 接口实现自动化操作。

6. **规模化管理**  
   随着业务增长，扩展云手机数量，集中、安全管理更多账号。
